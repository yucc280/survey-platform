# 后端测试说明

## 1. 测试程序设计

测试代码位于 [`backend/tests/`](../backend/tests/)，使用 Python `unittest` 和 FastAPI `TestClient`。每个测试按“准备隔离数据 → 发起接口请求或调用函数 → 断言状态码、响应及数据变化 → 清理环境”的流程执行。

| 测试文件 | 主要检查内容 |
| --- | --- |
| `test_auth.py` | 注册、登录、密码哈希和令牌认证 |
| `test_surveys.py` | 问卷创建与编辑、题型配置、跳转规则、生命周期、权限及草稿删除 |
| `test_responses.py` | 答题路径、答案校验、匿名、重复限制和提交保存 |
| `test_statistics.py` | 最新整份答卷统计、选项计数、平均值和匿名信息保护 |

测试结合两类环境：内存替身用于检查业务分支，真实 MongoDB 用于验证读写、聚合和索引约束。真实库测试使用随机命名的独立临时数据库，并设置清理逻辑，不使用业务数据库。跳转判断另有直接调用函数的测试。

## 2. 核心测试用例

下表归纳已有自动测试中的代表性场景，不逐条展开全部测试方法。输入与预期取自测试代码，实际输出概括本次通过的断言，不表示检查了响应中的全部字段。

公共数据：Alice、Bob 为测试账号；示例问卷含必答单选、恰选两项的必答多选、可选文本、0～120 的可选整数和启用格式校验的可选手机号题。题目和选项 ID 使用接口返回值。

| T01 注册与登录 | 注册，检查保存内容，登录后查询当前用户 | 用户名带首尾空格的 Alice，密码 `123456` | 注册 `201`，用户名去空格；保存密码哈希；当前用户查询 `200`，不返回哈希 | 符合预期，通过；内存测试 |
| T02 认证与权限 | 使用无效身份查询用户、操作他人问卷 | 缺失/过期/错误签名令牌；Bob 操作 Alice 问卷 | 无效认证 `401`；无权管理他人问卷 `404` | 符合预期，通过 |
| T03 创建问卷 | Alice 创建问卷，查询详情及数据库 | 标题“课程问卷”、说明“用于课程实验” | `201`；草稿、题目为空、截止为空、两开关默认关闭；创建者正确且已保存 | 符合预期，通过 |

| T08 答案校验 | 逐项替换合法答卷中的答案后提交 | 非法选项、重复多选、少选、超长文本、年龄 -1/121/1.5、错误手机号等 | 非法答案 `422` 且不保存；年龄 0、120、字符串 `20.0` 可通过预校验 | 符合预期，通过 |
| T09 预校验与提交 | 先预校验，再确认提交并读库 | 文本 `"  课程很好  "`、年龄 `"0"`、手机号 `"13800138000"` 及合法选择答案 | 预校验 `200` 且不写库；提交 `201`，文本去空格、数字规范化，保存内容与预校验一致 | 符合预期，通过 |

| T13 统计口径 | Bob 提交两份，Alice 提交一份，创建者查询 | Bob 年龄 20→40，Alice 年龄 20，同时改变选择与文本 | 总份数 3、参与人数 2；按最新整份答卷计数，年龄平均值 30 | 符合预期，通过 |
| T14 统计空值与匿名 | 查询空问卷，再检查空答、0、最新跳过及匿名切换 | 无答卷；文本空答、年龄 0；同账号新答卷跳过旧题；实名→匿名 | 空平均值为 `null`；0 参与平均；跳过不从历史回填；匿名样本用户名为空，不返回内部身份字段 | 符合预期，通过 |
| T15 草稿删除 | 本人删除草稿，再查询列表与详情；检查非法删除 | 本人、未登录、其他账号及非法 ID | 本人删除 `200`，文档消失、详情 `404`、列表更新；未登录 `401`，其他非法访问 `404`，目标保留 | 符合预期，通过 |

## 3. 测试结果与分析

本次由本人执行后端自动测试，共运行 **84 项，全部通过，失败 0 项、异常 0 项、跳过 0 项**，耗时 **10.226 秒**。其中 45 项为非真实库测试，39 项为真实 MongoDB 测试；同一业务用例在不同环境执行会分别计数，因此不代表 84 种独立场景。

结果表明，现有断言覆盖的问卷管理、配置与答案校验、路径计算、答卷保存和统计行为符合预期。真实库测试还验证了两请求并发提交时的唯一性约束，以及实际聚合统计结果。

本次范围为后端自动测试，不包含页面交互、大规模并发或大样本性能测试；账号注册未进行真实库并发验证。通过结果也不代表关闭问卷与插入答卷具备跨集合事务原子性。
